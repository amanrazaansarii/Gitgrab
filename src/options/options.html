GitHub Authentication (Personal Access Token)

Checking rate limit...

GitHub restricts unauthenticated API calls to 60 requests per hour. Adding a free token raises your rate limit to 5,000 requests per hour and enables downloading from private repositories.

💡 How to create a free GitHub Token:
  1. Go to GitHub Settings → Developer Settings → Personal access tokens (classic).
  2. Set note to GitGrab Extension and expiration to No expiration (or your choice).
  3. No scopes needed for public repositories. (Check repo scope only if you want to download from private repos).
  4. Click Generate token and paste it above.
